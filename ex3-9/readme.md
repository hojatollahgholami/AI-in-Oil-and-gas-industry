Ref: Ntafalias, A., Chrysovalantis, S., Lamprinoudakis, P., & Kitsatoglou, A. (2025). Refinery Compressor Sensor Data, One-Year Dataset [Data set]. Zenodo. https://doi.org/10.5281/zenodo.14866092
This set of measurements, collected over a period of one year (01/01/2022-31/12/2022), was derived from a refinery’s distributed control system (DSC) and was used for monitoring the compressor's operation. Key variables such as turbine axial displacement and oil temperature are monitored, offering invaluable insights into the compressor's behaviour. These variables are monitored through 25 sensors and the dataset contains approximately 35036 readings for each one of them. 

Notes
ZI: Axial displacement indicator

PI: Pressure indicator

TI: Temperature indicator

SI: Speed indicator
